# excel gantt chart

## how to use
- put starting day in G1
- put current day in F1 (for red vertical bar indication)
- put offset from starting day in E1 (this is set by the slider normally)

## v2 vs v3
- in v2 there is no workpackage definition, everything is done on the planning tab
- in v3 work packages and tasks are set up in the wp tab, they are referenced by index in the planning tab and planned there
